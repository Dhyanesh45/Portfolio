# S J Dhyanesh | Portfolio

Personal portfolio website for S J Dhyanesh — BI Developer & Data Analytics Professional. Built with React and Vite, deployed to GitHub Pages.

## Sections

- **Hero** — introduction and headline
- **About** — background and summary
- **Experience** — professional work history
- **Skills** — technical skills
- **Education** — academic background
- **Certifications** — professional certifications
- **Research** — research work
- **Contact** — contact form and details

## Tech Stack

- [React](https://react.dev/)
- [Vite](https://vitejs.dev/)
- [gh-pages](https://www.npmjs.com/package/gh-pages) for deployment

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Deploy

```bash
npm run deploy
```

This builds the site and publishes the `dist` folder to the `gh-pages` branch on GitHub Pages.
